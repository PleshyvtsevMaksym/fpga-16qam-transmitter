16-QAM DSP REFERENCE MODEL - PROJECT OVERVIEW
=============================================

HOW TO RUN (from the 02_DSP_Model folder, in PowerShell)
---------------------------------------------------------
  py main.py          run both pipelines, print the report, show the figures
  py -m tests.test    run all tests, PASS/FAIL summary at the end

Use "py", not "python": "python" here starts a Python 3.13 without NumPy.
Run from 02_DSP_Model so params.py and the packages are found.


ARCHITECTURE
------------
  params.py          all parameter values (transmitter, FPGA word widths,
                     hardware datasheet values), no code
      |
  pipeline/fpga_pipeline.py      fpga/ = the FPGA: ideal reference (01-07)
      |                          and bit-true fixed-point model (08-09)
      |                          -> IF samples sent to the DAC
  pipeline/hardware_pipeline.py  hardware/ = what happens after the FPGA
      |                          (DAC, clock, filter, output stage; datasheet units)
      |                          -> transmitter output
  analysis/          virtual instruments (spectrum, VSA/EVM, later RF metrics), only measure
  visualization.py   all figures (clean FPGA signal + noisy output), only plot
  main.py            entry point: runs everything, SHOW_* switches
  tests/             checks every stage and the whole chain independently

Processing chain:
  PRBS15 bits -> Gray 16-QAM mapping -> normalization (/sqrt(10))
  -> zero-insertion upsampling (x100) -> RRC filter design
  -> FIR pulse shaping -> quadrature IF modulation (5 MHz)      [FPGA]
  -> quantization -> nonlinearity/offset -> clock jitter/phase noise
  -> zero-order hold -> DAC noise -> filter -> output stage    [hardware]
  -> spectrum / EVM                                              [analysis]


FILES
-----
params.py
    All parameter values: symbols, rates, IF, RRC roll-off/span, and the
    hardware values (datasheet or marked ASSUMPTION; None = effect off).

main.py
    Entry point. SHOW_* switches at the top turn single figures on/off.

fpga/__init__.py
    Loads the numbered modules with importlib (names starting with a digit
    cannot be imported normally) and exports the functions, so you can
    write: from fpga import design_rrc

fpga/01_prbs15_generation.py         prbs15_generator: 15-bit LFSR, seed 0x0001
fpga/02_16qam_gray_mapping.py        qam16_gray_mapping / qam16_gray_demapping
fpga/03_symbol_normalization.py      normalize_symbols: divide by sqrt(Es)
fpga/04_zero_insertion_upsampling.py upsample_symbols: symbol + (sps - 1) zeros
fpga/05_rrc_filter_design.py         design_rrc: unit-energy RRC coefficients
fpga/06_fir_pulse_shaping.py         apply_fir: full linear convolution
fpga/07_quadrature_if_modulation.py  modulate_to_if: I cos - Q sin
fpga/08_fixed_point_arithmetic.py   quantize_coefficients, shift_right (round/truncate),
                                    saturate, required_bits: bit-true integer operations
fpga/09_nco.py                      generate_nco: DDS (phase accumulator + cos/sin LUT)

hardware/01_awgn.py                    add_awgn: noise at a given SNR (theory figures)
                                    add_dac_noise: DAC noise floor from NSD (dBFS/Hz)
hardware/02_dac_quantization.py        quantize_dac: N-bit two's complement DAC
                                    compute_full_scale: full scale from peak + back-off
hardware/03_clock_jitter.py            add_clock_jitter: oscillator + DAC RMS jitter
hardware/04 ... 09                     phase noise, nonlinearity, offset/gain error,
                                    zero-order hold, reconstruction filter,
                                    output stage (to be written)

analysis/01_fft_spectrum.py         compute_spectrum: |X[k]|/N in dB (virtual spectrum analyzer)
analysis/02_evm.py                  demodulate_if: VSA (delay, gain, phase sync from known
                                    symbols); compute_evm: RMS EVM in %
analysis/03_rf_metrics.py           PSD in dBm/Hz, ACLR, SFDR (to be written)

pipeline/fpga_pipeline.py
    run_fpga_pipeline(): connects fpga stages 01-07 and returns a
    dictionary with every intermediate array.
    run_fpga_fixed_point_pipeline(): the same transmitter with the FPGA
    word widths (params section 4); returns integer DAC codes and the
    same signal in ideal units. Golden reference for the HDL testbench.

pipeline/hardware_pipeline.py
    run_hardware_pipeline(): IF samples -> noise models in physical order
    -> transmitter output.

pipeline/pipeline_report.py
    Terminal report: configuration and the size of every stage output.
    [DONE] means "executed", not "verified".

visualization.py
    plot_constellation, plot_symbol_processing, plot_rrc_response,
    plot_if_waveform and plot_spectra (clean FPGA signal + noisy transmitter
    output), plot_noisy_constellation (theory illustration: AWGN on symbols).

tests/test.py
    Runs every tests/test_*.py file and prints PASS / FAIL / ERROR / SKIPPED.

tests/test_01_prbs15.py ... tests/test_08_spectrum.py
    One file per DSP stage (test_08 = analysis/01_fft_spectrum). Expected
    values come from hand calculations, definitions and known signal properties.

tests/test_10_fixed_point.py
    Fixed-point arithmetic by hand, DDS, and the bit-true pipeline vs ideal.

tests/test_09_end_to_end.py
    Whole FPGA pipeline: array lengths, baseband and IF consistency,
    bandwidth, and an independent reference receiver that recovers all bits.

To run one test file only:  py -m unittest tests.test_05_rrc_design -v
